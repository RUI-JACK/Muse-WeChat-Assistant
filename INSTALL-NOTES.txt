Muse 微信助手 1.0.0

适用：Windows 10 2004 及以上 / Windows 11，Intel 或 AMD x64。当前实际安装验证为 Windows 11 x64；不是 macOS、Linux、ARM64 或所有微信版本通用安装包。

安装包内含 Python 3.11、Tcl/Tk、固定版本 Python 依赖和 Microsoft C++ 运行库安装程序。Python 依赖离线安装，不会依赖构建者电脑的盘符、用户名或 Python。
缺少系统 C++ 运行库时会请求一次管理员授权。群聊还需要 Windows 中文 OCR；缺失时可勾选安装组件或在开始菜单选择“安装中文文字识别”，需要管理员权限及 Windows 更新网络。

微信与 Muse 不随包分发，也不包含任何人的登录信息。请自行安装微信 4.1.15.56，登录微信；使用“打开 Muse”快捷方式登录自己的 Muse 账号。其他微信版本会被阻止，需重新适配验收。

开始前选择私聊或群聊，输入当前聊天顶部的准确名称；群聊另填本人群昵称。群聊仅被 @ 时回复。开启自动点击 Y 会自动确认并发送本机草稿；关闭后等待人工确认。

微信与 Muse 必须在可交互的 Windows 桌面会话中保持可用。锁屏、注销、最小化窗口、切换到其他会话可能中断监听；安装包不提供脱离桌面的后台接口。

聊天内容和图片会发送到你登录的 Muse。上下文以可读文件保存于运行用户的“文档\聊天上下文”；其他本地记录位于安装目录 local。升级保留现有配置，卸载保留用户文档、local 记录及独立浏览器登录目录。

请仅在自己账号及获得相关人员同意的场景使用。程序无法保证模型回复总是准确或适当，建议先关闭自动点击 Y 验证效果。
